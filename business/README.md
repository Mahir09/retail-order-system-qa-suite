# Business Analysis Documentation

This folder contains the business requirements and process documentation for the RetailHub Buy Online, Pick Up In Store (BOPIS) QA portfolio project.

- **BRD.md** — Documents functional and non-functional requirements, business rules, risks, and success metrics.
- **user-stories.md** — Translates business requirements into user stories with Given/When/Then acceptance criteria.
- **UAT-plan.md** — Defines UAT objectives, participants, entry and exit criteria, test data, scenarios, defect handling, and sign-off.
- **requirements-traceability.xlsx** — Maps requirements to user stories and UAT scenarios, with space for future test cases, execution status, and defects.
- **process-diagrams/** — Contains the As-Is and To-Be BOPIS workflow diagrams in editable draw.io and PNG formats.
